01 · The Challenge

A real face is not a stylized character.

Traditional facial capture records a human performance accurately, but production teams still pay for the capture setup and then lose fidelity while retargeting that human face onto characters with very different proportions and performance styles.

01

High setup cost

Actors, recording environments, capture devices, calibration, cleanup, and retakes make early performance exploration expensive.

02

Style mismatch

Human facial motion does not naturally match every stylized character, so retargeting introduces precision loss and manual correction.

03

Broken handoff

Many AI talking-head tools stop at video. Animation teams need curves, controls, and data that the DCC and engine can consume.

The generated video is not the final deliverable. It becomes a character-matched performance source for automated facial solving.

02 · System

One pipeline, five handoffs.

I consolidated model orchestration, performance direction, cloud task management, preview, facial solving, and DCC delivery into one repeatable flow.

01

Character + Voice

Upload a character source image and recorded audio, or synthesize the line with TTS.

02

Performance Direction

Select personality, emotion, and intensity instead of writing a fragile free-form prompt.

03

Generative Performance

LLM + AU rules, TTS, LoRA, and the video model produce a character-aware performance.

04

Facial Solve

Video frames become expression, gaze, head-pose, mouth, and timing data.

05

Maya + Unreal

Export JSON / animation data, preview on MetaHuman, and import the result back to Maya.

03 · Product Surface

The pipeline lives inside Maya.

The tool hides service addresses, ComfyUI nodes, media conversion, request packaging, and polling. Artists stay in the DCC and provide only the inputs that affect the performance.

Four artist-facing steps

Install once. Generate without leaving the scene.

The plugin is packaged as a productized Maya shelf tool with bundled media utilities and automated environment checks.

  1. 01
    Drag to install.
    Drop one installer script into Maya to create the shelf button.
  2. 02
    Choose the performance.
    Select the character, audio, personality, emotion, intensity, and output path.
  3. 03
    Submit in the background.
    Authenticate, normalize media, package the request, and poll the cloud task without blocking Maya.
  4. 04
    Preview and continue.
    Review the returned video, then solve it in Unreal or import facial data back to Maya.

Direction becomes structured data.

The control model separates long-term personality, current emotion, and performance intensity. Each selection maps to tested description fragments and AU guidance before entering the generation workflow.

Personality = persistent acting tone

Controls micro-expression frequency, eye intensity, and the character's overall behavioral tendency.

Base constraints, negative controls, AU logic, and a recorded seed reduce semantic conflicts and improve reproducibility.

06 · Production Handoff

Preview first. Solve second. Deliver data.

The artist can inspect the generated performance before spending time on solving and transfer. Once approved, the same tool checks the Unreal environment, creates facial animation, exports JSON, and sends the result back to the Maya controls.

Output logic

Pixels become animation controls.

Expression weights, head pose, eye motion, mouth motion, frame rate, and timing are packaged for engine and DCC use. Optional head-motion transfer keeps facial-only and full-performance workflows separate.

07 · Invention Logic

A character-aware alternative to human retargeting.

The patent draft describes an end-to-end method that constrains generation with the character's own visual identity, structured performance parameters, audio rhythm, and duration—then converts the video result into animation resource data.

Instead of capturing a human and correcting the mismatch later, the system generates the performance in the character's style first.

09 · Honest Reflection

The next milestone is stability.

The full chain works. The next phase is not adding more features; it is turning subjective model tests into repeatable quality criteria and reducing deployment friction.

Needs validation

LLM + AU consistency

Different combinations need broader testing to prove that the intended performance dimensions remain distinct and repeatable.

Needs validation

Expression-reference strength

Normal references have limited influence, while extreme expressions can distort facial proportions and character identity.

Deployment risk

Model and dependency footprint

Large models, node packages, paths, and Unreal prerequisites still create onboarding friction despite automated checks.

Evaluation gap

Wan / Seedance comparison

Model comparisons need fixed inputs and shared criteria for identity, lip sync, expression naturalness, speed, and cost.
